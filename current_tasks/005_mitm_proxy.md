# Task: MITM Proxy (YOLO mode)

**Status:** not started

**What to do:**
1. Implement the MITM proxy in `crates/closedshell-lib/src/proxy.rs`
2. The proxy listens on localhost:<port> and handles HTTP CONNECT tunneling:
   a. Client sends `CONNECT host:443 HTTP/1.1`
   b. Proxy responds `200 Connection Established`
   c. Client starts TLS handshake — proxy terminates it using session CA + dynamic leaf cert (tls module)
   d. Proxy reads the HTTP request from the decrypted stream
   e. Parse request into RequestInfo, call `parser::parse_action()`
   f. Log decision via audit log (in YOLO mode: always "allow (yolo)")
   g. Establish new TLS connection to the real upstream (using system trust store, NOT session CA)
   h. Forward the request, relay the response back through the proxy TLS connection
3. Must support:
   - HTTP/1.1 keepalive (multiple requests per connection)
   - Chunked transfer encoding (streaming)
   - WebSocket upgrade (after initial request, become a bidirectional pipe)
   - Large responses (stream through, don't buffer entire body)
4. Use tokio for async I/O, rustls for TLS, hyper for HTTP parsing
5. The proxy struct should take a reference to SessionCA and AuditLog

**Dependencies:** task 003 (session CA), task 004 (parsers)

**Tests that must pass:**
- `cargo test -p closedshell-lib proxy`
- Manual test: `HTTPS_PROXY=http://localhost:8443 SSL_CERT_FILE=/tmp/ca.pem curl https://httpbin.org/get`
